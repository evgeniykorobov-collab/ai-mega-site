# Релей заявок НейроАктив

Cloudflare Worker между формой на сайте и Telegram. Нужен затем, что сайт живёт на
GitHub Pages — сервера там нет, а класть токен бота в браузер нельзя: его видно
через DevTools любому посетителю, и им можно писать и читать от лица бота.

## Что нужно один раз

**1. Бот и канал в Telegram**

- Написать [@BotFather](https://t.me/BotFather), команда `/newbot`, получить токен вида `1234567890:AA...`
- Создать приватный канал для заявок, добавить туда бота администратором
- Узнать id канала: либо `@имя_канала`, если он публичный, либо числовой id

**2. Cloudflare**

Бесплатный аккаунт на [dash.cloudflare.com](https://dash.cloudflare.com). Карта не нужна.
Лимит бесплатного плана — 100 000 запросов в сутки, для формы это в тысячи раз с запасом.

## Развернуть

```bash
cd worker
npm install -g wrangler
wrangler login

wrangler secret put TELEGRAM_BOT_TOKEN   # вставить токен от BotFather
wrangler secret put TELEGRAM_CHAT_ID     # @канал или числовой id

wrangler deploy
```

Wrangler напечатает адрес вида `https://neiroaktiv-lead-relay.<аккаунт>.workers.dev`.

## Подключить к сайту

Положить адрес в `.env.production` в корне сайта:

```
VITE_LEAD_ENDPOINT=https://neiroaktiv-lead-relay.<аккаунт>.workers.dev
```

Пересобрать и задеплоить. `.env.production` в git не попадает — правило `.env*`
в `.gitignore` это закрывает (проверено `git check-ignore`). Образец полей лежит
в `.env.example`, он как раз отслеживается.

## Пока релей не развёрнут

Сайт работает: форма не показывает ошибку, а открывает Telegram с уже подставленным
текстом заявки и показывает его же на экране вместе с телефоном. Заявка доходит,
просто руками посетителя. Это временный режим, не постоянное решение.

## Проверить, что живой

```bash
curl -X POST https://neiroaktiv-lead-relay.<аккаунт>.workers.dev \
  -H "Content-Type: application/json" \
  -H "Origin: https://neiroaktiv.ru" \
  -d '{"name":"Проверка","phone":"+79000000000","niche":"тест"}'
```

Ожидается `{"ok":true}` и сообщение в канале.

## Что Воркер делает с данными

Принимает POST только с `neiroaktiv.ru`. Обрезает поля по длине, требует имя и
телефон минимум с семью цифрами, экранирует HTML. Пересылает в Telegram и забывает —
ничего не хранит и не логирует, кроме кода ошибки при сбое доставки.
